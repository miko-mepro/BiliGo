## 1. 核心工作流总览（5 步）

### 1.1 系统 Prompt（来自旧 `ChatContext.tsx:105-119`，原样迁移）

```
你是 Bilibili 视频搜索助手。请严格按以下工作流处理用户请求：

1. **理解黑话**：如果用户输入包含网络梗、俚语、缩写（如"退退退/绝绝子/yyds/破防"），先调用 slang_understand 把意图标准化。
2. **扩展查询**：调用 query_expand 把标准化后的意图扩展成多个候选关键词/标签。
3. **搜索视频**：调用 bilibili_search 执行搜索。仅在用户明确说"按封面搜/看封面"时才把 analyze_covers 设为 true。
4. **智能重排**：当 bilibili_search 返回多于 3 个结果时，调用 video_rerank 重排，把最相关的放最前面。
5. **展示或澄清**：如果你对结果有信心，直接用自然语言总结并展示；如果意图非常模糊或多义且本会话还没追问过，调用 ask_clarification 追问（每会话最多 1 次）。

硬性规则：
- 单次会话工具调用不超过 5 轮，超过就停止调用工具直接回答。
- 不要跳过第 1、2 步直接搜索；除非用户输入已经是非常具体、明确的标准中文关键词。
- 每次工具调用前先简短说明你的计划，再发起调用。
- 当用户只是闲聊或问与视频搜索无关的问题时，可以直接回答，不调用任何工具。
```

## 2. SW 端 streamText 主流程

### 2.1 伪代码

```python
function handleChat(port, state, msg):
    # 1. 读取配置
    settings = await readBiliAgentSettings()
    config = settings.providers.find(p => p.id == settings.activeProviderId)

    validation = validateProviderConfig(config)
    if not config or not validation.valid:
        postToPort(port, error("请到设置配置 AI 提供商", "PROVIDER_NOT_CONFIGURED"))
        postToPort(port, done)
        return

    # 2. 创建 model
    model = createModel(config)  # AI SDK LanguageModel

    # 3. 转换 UI 消息；SYSTEM_PROMPT 只通过 streamText.system 传入
    modelMessages = toModelMessages(msg.messages)

    # 4. 准备 tools（AI SDK tool() 格式，注入 port+state 用于推送消息）
    tools = {
        slang_understand:  makeSlangUnderstandTool(port, state),
        query_expand:     makeQueryExpandTool(port, state),
        bilibili_search:   makeBilibiliSearchTool(port, state),
        video_rerank:      makeVideoRerankTool(port, state),
        ask_clarification: makeAskClarificationTool(port, state),
    }

    # 5. 调用 streamText
    abortController = new AbortController()
    result = streamText({
        model,
        system: SYSTEM_PROMPT,
        messages: modelMessages,
        tools,
        stopWhen: isStepCount(5),   # 最多 5 个已完成的模型 step
        abortSignal: abortController.signal,
    })

    # 6. 消费 stream 推流
    try:
        stream_loop: for part in result.stream:
            if state.disconnected: return
            switch part.type:
                case 'text-delta':
                    postToPort(port, chunk(part.text))
                case 'reasoning-delta':
                    postToPort(port, reasoning(part.text))
                case 'tool-call':
                    postToPort(port, tool_start(part.toolCallId, part.toolName, part.input))
                case 'tool-result':
                    postToPort(port, tool_result(part.toolCallId, part.toolName, part.output))
                case 'tool-error':
                    postToPort(port, error(friendlyMessage(part.error), inferCode(part.error)))
                    break stream_loop
                case 'abort':
                    break stream_loop  # 用户中断，静默；循环后统一 done
                case 'error':
                    postToPort(port, error(friendlyMessage(part.error), inferCode(part.error)))
                    break stream_loop
    except AbortError:
        pass  # 用户中断，静默
    except Exception as e:
        postToPort(port, error(friendlyMessage(e), inferCode(e)))

    postToPort(port, done)
```

## 3. Step 1: slang_understand（黑话理解）

### 3.1 算法流程

```
┌─────────────────────────────────────────────────────────┐
│ 输入: query (用户原始文本)                                │
└────────────────────┬────────────────────────────────────┘
                     ▼
        ┌────────────────────────┐
        │ query.trim() 为空？    │
        └──────┬─────────┬───────┘
           是  │         │ 否
               ▼         ▼

        │ 返回空   │  │ findInDictionary()   │

                              ▼
                   ┌──────────────────────┐
                   │ 命中字典？           │
                   └──────┬─────────┬─────┘

### 3.2 伪代码

```python
function slang_understand_execute(query):
    original = query
    trimmed = query.trim()

    if not trimmed:
        result = { original, normalized: original, explanation: "输入为空", matchedDict: False }
        updateMemory(triedKeywords=[normalized])
        return result

    # 1. 本地字典匹配（最长匹配）
    dictHit = findInDictionary(trimmed)
    #    遍历 slang-dictionary.json 的 entries
    #    对每个 entry 的 [term, ...aliases]，检查 lower.includes(candidate.lower())
    #    取匹配长度最长的 entry

    if dictHit:
        normalized = dictHit.searchHints[0] if dictHit.searchHints else dictHit.meaning
        result = { original, normalized, explanation: dictHit.meaning, matchedDict: True }
    else:
        # 2. LLM 标准化
        messages = [
            { role: 'system', content: SLANG_SYSTEM_PROMPT },
            { role: 'user', content: trimmed }
        ]
        parsed = await callLlmForJson(messages)  # {normalized, explanation}

        if parsed and parsed.normalized:
            result = { original, normalized: parsed.normalized, explanation: parsed.explanation or FALLBACK, matchedDict: False }
        else:
            result = { original, normalized: original, explanation: "无法理解，按原文搜索", matchedDict: False }

    updateMemory(triedKeywords=[result.normalized])
    postToPort(insight(kind='understanding', data=result))
    return result
```

### 3.3 关键约束

- **字典最长匹配**：多个 term/alias 命中时取字符长度最长的（避免 "yy" 误匹配）
- **LLM 失败降级**：返回 `normalized=原文`，不阻断流程
- **memoryStore 同步**：`triedKeywords` 追加（供后续工具查询）
- **explanation 字数**：<= 40 字

### 4.2 伪代码

```python
function query_expand_execute(query):
    seed = [query.trim()].filter(not empty)

    # 1. 并行获取辅助上下文（失败容忍）
    suggest = await safeCall(lambda: searchSuggest(seed[0]) if seed[0] else [])
    hot = await safeCall(lambda: searchHot(20))

    # 2. 本地字典匹配
    haystack = (query + ' '.join(seed)).lower()
    matchedTags = tagTable.popularTags.filter(tag => haystack.includes(tag.lower()))
    matchedCategories = tagTable.categories
        .filter(cat => haystack.includes(cat.name.lower()))
        .map(cat => cat.name)

    # 3. LLM 生成扩展
    prompt = f"User intent: {query}\nSeed: {seed}\nSuggest: {suggest}\nHot: {hot}\n..."
    messages = [
        { role: 'system', content: EXPAND_SYSTEM_PROMPT },  # 限制 keywords<=8 等
        { role: 'user', content: prompt }
    ]
    parsed = await callLlmForJson(messages)

    # 4. 结果处理
    if parsed and parsed.keywords:
        result = {
            keywords: dedupe(parsed.keywords).slice(0, 8),
            tags:     dedupe(parsed.tags).slice(0, 5),
            categories: dedupe(parsed.categories).slice(0, 3),
            rationale: parsed.rationale or 'fallback'
        }
    else:
        result = { keywords: dedupe(seed).slice(0, 8), tags: [], categories: [], rationale: 'fallback' }

    # 5. 更新记忆 + 推送 insight
    recordToMemory(triedKeywords=merged)
    postToPort(insight(kind='expansion', data=result))
    return result
```

### 4.3 关键约束

- **safeCall 容错**：searchSuggest/searchHot 失败返回空数组，不阻断
- **去重**：`Array.from(new Set(arr))`
- **截断顺序**：先去重再截断（避免截断后还有重复）
- **memoryStore 合并**：`triedKeywords = [...existing, ...new]` 去重

### 5.2 伪代码

```python
function bilibili_search_execute(keyword, order, analyze_covers):
    if not keyword or not keyword.trim():
        throw Error("bilibili_search requires a keyword argument")

    # 1. 获取 SESSDATA
    sessdata = await getSessdata()  # chrome.cookies.get

    # 2. 搜索
    opts = parseSearchOptions({ page, pageSize, order })
    videos = await searchVideo(keyword, opts, sessdata)
    #   -> WBI 签名（6h 缓存）-> fetch -> 映射 BilibiliVideoCard

    # 3. 封面分析（可选）
    if analyze_covers == True:
        covers = videos
            .filter(v => v.bvid and v.pic)
            .map(v => ({ bvid: v.bvid, picUrl: v.pic }))
            .slice(0, 5)  # HARD_MAX_COVERS
        if covers:
            descriptions = await analyzeCovers(covers, 5)
            videos = videos.map(v => {
                desc = descriptions.get(v.bvid)
                return desc ? { ...v, coverDescription: desc } : v
            })

    # 4. 推送视频列表 + 工具结果
    postToPort(videos(videos))
    return videos
```

### 5.3 关键约束

- **SESSDATA 可选**：缺失时游客搜索（可能触发风控，返回 BilibiliRiskError）
- **WBI 签名**：6 小时 key 缓存，自动刷新（`wbi.ts`，无需改动）
- **封面分析硬上限**：5 张（`HARD_MAX_COVERS`）
- **风控处理**：code=-352 抛 `BilibiliRiskError`，SW 端应转为 `error` 消息（code=`BILIBILI_RISK`）

                    │ clamp[0,1]   │  │ score=1-index*0.01   │
                    │ 按 score 降序│  │ reason='fallback'    │
                    │ strategy=   │  │ strategy='fallback'  │
                    │ 'llm'        │  └──────────┬───────────┘
                    └──────┬───────┘             │
                           └──────────┬──────────┘
                                      ▼
                    ┌──────────────────────────────┐
                    │ 推送 insight(rerank)          │
                    │ 推送 videos(重排后列表)       │
                    │ 更新 memoryStore              │
                    └──────────────────────────────┘
```

### 6.2 伪代码

```python
function video_rerank_execute(videos, intent):
    truncated = videos.slice(0, 30)  # MAX_CANDIDATES
    trimmed = max(0, videos.length - 30)

    if not truncated:
        memoryStore.update({})
        return { items: [], strategy: 'fallback', trimmed }

    # 1. 并行获取标签（失败容忍）
    tagResults = await Promise.allSettled(
        truncated.map(v => fetchVideoTags(v.bvid))
    )
    tagsByBvid = Map()
    truncated.forEach((card, i) => {
        result = tagResults[i]
        tags = result.status == 'fulfilled'
            ? result.value.map(t => t.tag_name).filter(not empty)
            : []
        tagsByBvid.set(card.bvid, tags)
    })

    # 2. LLM 打分
    try:
        prompt = buildPrompt(intent, truncated, tagsByBvid, coverDescriptions)
        parsed = await callLlmForJson([{ role:'user', content: prompt }])
        if not parsed or not parsed.items:
            throw Error('empty rerank items')

        normalized = normalizeRerankItems(parsed.items, truncated)
        #   - 过滤 bvid 不在 candidates 中的
        #   - score = clamp(score, 0, 1)
        #   - 缺失 score = 0
        sorted = normalized.sort((a, b) => b.score - a.score)
        memoryStore.update({})
        result = { items: sorted, strategy: 'llm', trimmed }
    except error:
        memoryStore.update(failureReasons=[...existing, f"rerank_fallback:{error}"])
        result = {
            items: truncated.map((card, i) => ({
                bvid: card.bvid,
                score: 1 - i * 0.01,  # 递减保证稳定
                reason: 'fallback'
            })),
            strategy: 'fallback',
            trimmed
        }

    # 3. 推送 insight + 重排后视频
    postToPort(insight(kind='rerank', data=result))
    reordered = result.items
        .map(item => videos.find(v => v.bvid == item.bvid))
        .filter(not null)
    postToPort(videos(reordered))
    return result
```

### 6.3 关键约束

- **MAX_CANDIDATES=30**：超过截断，`trimmed` 记录截断数
- **score 范围**：[0, 1]，超出用 `clamp` 限制
- **bvid 校验**：丢弃 LLM 返回的不在 candidates 中的 bvid
- **fallback 稳定排序**：`score = 1 - index * 0.01`，保证原序且分数递减

## 8. callLlmForJson（LLM JSON 调用，工具内部使用）

### 8.1 算法

```python
function callLlmForJson(messages):
    try:
        settings = await readBiliAgentSettings()
        if not settings.activeProviderId: return null

        provider = settings.providers.find(p => p.id == activeProviderId)
        if not provider or not provider.model: return null

        # 旧版：createProvider + provider.chat 流式累积
        # 迁移后：generateObject({ model, schema, messages }) 或 generateText + 解析
        accumulated = ''
        for env in provider.chat({ messages }):
            if env.type == 'delta': accumulated += env.text
            elif env.type == 'error': return null
            elif env.type == 'done': break

        if not accumulated.trim(): return null
        return parseJsonFromText(accumulated)
    except:
        return null
```

### 8.2 JSON 解析容错（`parseJsonFromText`）

```python
function parseJsonFromText(text):
    trimmed = text.trim()
    # 1. 去除 markdown 代码块
    stripped = trimmed
        .replace(/^```(?:json)?\s*/i, '')
        .replace(/```\s*$/, '')
        .trim()

    # 2. 提取第一个 { 到最后一个 }
    first = stripped.indexOf('{')
    last = stripped.lastIndexOf('}')
    if first < 0 or last <= first: return null

    candidate = stripped.slice(first, last + 1)
    try:
        return JSON.parse(candidate)
    except:
        return null
```

### 8.3 迁移建议

迁移到 AI SDK 后，建议改用 `generateObject()`：
```typescript
import { generateObject } from 'ai';
import { z } from 'zod';

const { object } = await generateObject({
  model,
  schema: z.object({
    normalized: z.string(),
    explanation: z.string(),
  }),
  messages,
});
```

好处：无需手动解析 JSON，schema 校验自动。但需注意 `generateObject` 不支持所有 provider（见风险 R8）。

## 10. 工具调用轮次控制

### 10.1 旧版（手写 loop）

```python
for round in range(5):  # MAX_TOOL_ROUNDS
    requestedTool = False
    for env in chatViaBackground():
        if env.type == 'tool_call':
            requestedTool = True
            result = await resolveToolCall(env.toolCall)
            messages.push(assistant_msg)
            messages.push(tool_msg)
            break  # 本轮结束，进入下一轮
        if env.type == 'done':
            return  # 无工具调用，完成
    if not requestedTool:
        return  # LLM 无工具调用，完成
throw Error("TOOL_ROUND_LIMIT")
```

### 10.2 新版（AI SDK 自动）

```python
result = streamText({
    model,
    system,
    messages: modelMessages,
    tools,
    stopWhen: isStepCount(5),  # 一行替代整个 loop
    abortSignal,
})
```

**优势**：
- 工具调度、结果回填、轮次判断全由 AI SDK 内部处理
- 代码减少 ~75 行
- 行为更可靠（无手写 break/continue 边界条件）

### 10.3 isStepCount(5) 语义

- 一个 AI SDK step 是一次模型生成步骤，可能包含零个、一个或多个工具调用
- `isStepCount(5)` 限制最多 5 个已完成的模型 step，不等同于“最多调用 5 次工具”
- 达到上限后停止继续模型循环，不保证 SDK 再额外运行一个 step 生成总结；system prompt 应鼓励模型在预算内完成最终回答
- 不会抛 `TOOL_ROUND_LIMIT` 错误；该错误码只为旧版兼容或应用层显式守卫保留
- 本文的“5 步业务工作流”是五个语义阶段，不要求与 AI SDK 的五个 step 一一对应

**错误归一化**（来自旧 `ChatContext.tsx:1042-1097`）：
```python
function normalizeStreamError(error):
    if isErrorPayload(error): return error
    message = error.message or "Unknown error"
    code = error.code or inferErrorCode(message)
    return { message: friendlyMessage(code, message), code }

function inferErrorCode(message):
    lower = message.lower()
    if '401' in message or '403' in message or 'api key' in lower or 'auth' in lower:
        return '401'
    if '429' in message or 'rate limit' in lower:
        return '429'
    return 'NETWORK_ERROR'

function friendlyMessage(code, fallback):
    if code in ['401','403','auth']: return 'API Key 无效，请检查设置'
    if code in ['429','rate_limit']: return '请求太频繁，请稍后重试'
    if code in ['NETWORK_ERROR','network']: return '网络连接失败'
    return fallback or '请求失败，请稍后重试'
```
