## 1. T01 - ChatMessage（对话消息）

**位置**：`lib/shared-types/index.ts`（从旧仓库 L1 直接迁移，无需改动）

```typescript
export interface ChatMessage {
  role: 'user' | 'assistant' | 'system' | 'tool';
  content: string;
  toolCalls?: ToolCall[];          // assistant 消息携带的工具调用
  toolCallId?: string;             // role='tool' 时对应 toolCall.id
  timestamp: number;               // 毫秒时间戳
  reasoning?: string;              // 模型思维链（DeepSeek reasoning_content），仅客户端
  steps?: AgentStep[];             // UI 时间线展示用
}
```

**字段约束**：
- `content`：必填，对 `role='tool'` 也是字符串（JSON 序列化的工具结果）
- `timestamp`：必填，由发送方填充（`Date.now()`）
- `reasoning` / `steps`：仅 UI 渲染使用，不参与 LLM 请求

**对接点**：
- CS → SW：`{ type: 'chat', messages: ChatMessage[], conversationId }`
- AI SDK `streamText({ messages })` 接收 `ChatMessage[]`（需做格式转换，见 §3.2）
- 持久化：`ConversationData.messages: ChatMessage[]`

## 2. T02 / T03 / T04 - 工具相关类型

```typescript
// T02 - 工具步骤（UI 时间线用）
export interface AgentStep {
  type: 'tool_call';
  name: string;          // 工具名，如 'bilibili_search'
  summary: string;      // 一句话摘要
  timestamp: number;
}

// T03 - 工具调用记录
export interface ToolCall {
  id: string;
  name: string;
  arguments: Record<string, unknown>;
}

// T04 - 工具定义（传给 LLM 的 JSON Schema）
export interface ToolDef {
  name: string;
  description: string;
  parameters: Record<string, unknown>;  // JSON Schema 对象
}
```

**迁移注意**：
- 迁移到 AI SDK 后，`ToolDef` 不再由前端硬编码（旧版 `ChatContext.tsx:20-103` 定义 5 个 `BILIBILI_TOOLS`），改由 `tool({ inputSchema, execute })` 在 SW 端定义（见 3.3）
- `ToolDef.parameters` 的 JSON Schema 由 AI SDK 自动从 zod schema 生成

## 3. T05 - ErrorPayload（错误归一化）

```typescript
export interface ErrorPayload {
  message: string;   // 已翻译为用户可读的中文
  code?: string;     // 见 §3.2 错误码表
}
```

**归一化规则**（来自旧 `ChatContext.tsx:1042-1097`）：
| 原始信号 | code | message |
|---------|------|---------|
| HTTP 401/403，含 "api key"/"auth" | `'401'` | `'API Key 无效，请检查设置'` |
| HTTP 429，含 "rate limit" | `'429'` | `'请求太频繁，请稍后重试'` |
| 其他网络异常 | `'NETWORK_ERROR'` | `'网络连接失败'` |
| Provider 未配置 | `'PROVIDER_NOT_CONFIGURED'` | `'请到设置配置 AI 提供商'` |
| 工具轮次超限 | `'TOOL_ROUND_LIMIT'` | `'工具调用次数过多，请换个说法再试'` |
| 其他 | 推断 code | 原始 message 或 `'请求失败，请稍后重试'` |

## 7. T10 - RerankResult（重排工具输出）

```typescript
export interface RerankItem {
  bvid: string;
  score: number;    // [0, 1]，1=完全匹配
  reason: string;   // 短理由
}

export interface RerankResult {
  items: RerankItem[];   // 已按 score 降序
  strategy: 'llm' | 'fallback';
  trimmed: number;        // 被截断的视频数（超过 MAX_CANDIDATES）
}
```

**工具输入**：
```typescript
z.object({
  videos: z.array(z.object({ bvid: z.string() }).passthrough()).describe('待重排视频'),
  intent: z.string().describe('用户搜索意图'),
})
```

**关键常量**：
| 常量 | 值 | 说明 |
|------|----|------|
| `MAX_CANDIDATES` | 30 | 重排候选上限 |

**fallback 策略**（LLM 失败时）：
- `strategy='fallback'`
- 保持原序，每个 `score = 1 - index * 0.01`（递减保证稳定排序）
- `reason='fallback'`

## 13. 工具结果 → Port 消息映射（跨模块对接点）

每个工具的 `execute()` 返回值，需在 SW 端同时推送两条 Port 消息（见 §3.2 协议）：

| 工具 | `tool_result.result` | 额外推送的 `insight` |
|------|---------------------|---------------------|
| `slang_understand` | `SlangUnderstandResult` | `{ type:'insight', kind:'understanding', data }` |
| `query_expand` | `QueryExpandResult` | `{ type:'insight', kind:'expansion', data }` |
| `bilibili_search` | `BilibiliVideoCard[]` | `{ type:'videos', videos }` |
| `video_rerank` | `RerankResult` | `{ type:'insight', kind:'rerank', data }` + `{ type:'videos', videos:重排后 }` |
| `ask_clarification` | `ClarificationRequest` | `{ type:'insight', kind:'clarification', data }` |

**对接约定**：CS 端 `dispatch` 根据 `insight.kind` 路由到 `ADD_UNDERSTANDING` / `ADD_EXPANSION` / `ADD_RERANK` / `SET_CLARIFICATION`（见 §3.4 ChatState）。

## 16. 接口对接矩阵（开发者独立实现的检查表）

开发者 A 实现 SW，开发者 B 实现 CS，两人只需对齐下表：

| 对接点 | SW 端产出 | CS 端消费 | 类型契约 |
|--------|----------|----------|---------|
| 文本流 | `{type:'chunk',delta}` | `APPEND_STREAMING` | `delta: string` |
| 推理流 | `{type:'reasoning',delta}` | `APPEND_REASONING` | `delta: string` |
| 工具开始 | `{type:'tool_start',toolName,args}` | `SET_ACTIVITY`+`ADD_STEP` | `ToolCall` |
| 工具结果 | `{type:'tool_result',toolName,result}` | （存入步骤） | `unknown` |
| 视频列表 | `{type:'videos',videos}` | `SET_VIDEOS` | `BilibiliVideoCard[]` |
| 洞察 | `{type:'insight',kind,data}` | `ADD_UNDERSTANDING` 等 | 见 §13 |
| 完成 | `{type:'done'}` | `CLEAR_STREAMING`+`SET_LOADING false` | - |
| 错误 | `{type:'error',message,code}` | `SET_ERROR` | `ErrorPayload` |
| 心跳 | `{type:'pong'}` | 重置超时计时器 | - |

**判定标准**：本表每一行的类型契约必须两侧一致，任一侧违反即视为对接失败。
