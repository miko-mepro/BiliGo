## 1. 整体布局

```
│           │ ┌─────────────────────────────┐   │                  │

│           │ ├─────────────────────────────┤   │                  │
│           │ │ Content Area                │   │                  │
│           │ │ (聊天 / 设置 两个视图)      │   │                  │

│           │ │                             │   │                  │
│           │ ├─────────────────────────────┤   │                  │
│           │ │ ChatInput（仅聊天视图）     │   │                  │
│           │ └─────────────────────────────┘   │                  │
│           └───────────────────────────────────┘                  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 智能定位规则

Panel 根据 ToggleButton 位置自动选择左/右侧（来自旧 `Panel.tsx:56-80` `computePanelPosition`）：

| 条件 | 位置 |
|------|------|
| 按钮右侧空间 >= 面板宽度 | 面板在按钮右侧 |
| 按钮左侧空间 >= 面板宽度 | 面板在按钮左侧 |
| 两侧都不够 | 放空间较大的一侧 |

### 1.3 尺寸约束

| 常量 | 值 | 说明 |
|------|----|------|
| `PANEL_GAP` | 8px | 面板与视口边缘间距 |
| `PANEL_MIN_WIDTH` | 280px | 最小宽度 |
| `PANEL_MIN_HEIGHT` | 300px | 最小高度 |
| 缩放方向 | 8 方向 | n/s/e/w/ne/nw/se/sw |
| 拖拽阈值 | 5px | 小于 5px 不触发拖拽 |

## 10. Shadow DOM 挂载

### 10.1 挂载结构

```typescript
// content/index.tsx
const HOST_ID = 'bili-agent-host';

function mountExtension() {
  // 防重复注入
  if (document.getElementById(HOST_ID)) return;

  const host = document.createElement('div');
  host.id = HOST_ID;
  host.style.cssText = 'position:fixed;width:0;height:0;z-index:10000';
  document.body.appendChild(host);

  const shadow = host.attachShadow({ mode: 'open' });

  // Constructable Stylesheets 注入（CSP 安全）
  const sheet = new CSSStyleSheet();
  sheet.replaceSync(cssText);  // 来自 styles.ts (1734 行)
  shadow.adoptedStyleSheets = [sheet];

  // React 根节点
  const root = document.createElement('div');
  shadow.appendChild(root);
  ReactDOM.createRoot(root).render(<App />);
}

// 注入时机：document_idle
```

### 10.2 关键约束

- `mode: 'open'`：允许 React DevTools 调试（见风险 R6）
- `position: fixed; width:0; height:0`：宿主零尺寸，不占布局空间
- `adoptedStyleSheets`：CSP 安全，不需要 `<style>` 标签
- 防重复注入：`getElementById` 检查
