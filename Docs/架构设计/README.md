# BiliGo 架构设计文档

## 文档概述

本目录包含 BiliGo（Bilibili 视频搜索 AI 助手 Chrome 扩展）的架构设计文档。

## 项目简介

**项目名称**: BiliGo (bili-go)
**项目类型**: Chrome Extension (Manifest V3)
**核心功能**: 基于 AI 的 Bilibili 视频智能搜索助手
**技术栈**: Vite 8 + React 19 + TypeScript 6 + Vercel AI SDK 7.x

## 架构迁移背景

BiliGo 正在从自写 llm-provider 架构迁移到 Vercel AI SDK 架构，以获得：
- 标准化的流式响应处理
- 内置的多模型提供商支持
- 工具调用（Tool Calling）标准化
- 更好的错误处理和重试机制

## 功能规模

根据功能盘点表（`../AvailableFeatures.md`），项目包含 **95 项功能**：
- **30 项需改动**（包括删除替换、重写、适配和 Tool 包装）
- **65 项保持不变**

## 核心设计原则

1. **分层隔离**: L0～L8 共 9 层，上层依赖下层，依赖关系以 2.2 的依赖表为准
2. **通信解耦**: Content Script ↔ Service Worker 通过 Port 消息通信
3. **标准化集成**: 使用 Vercel AI SDK 统一接口包装所有 LLM 提供商
4. **渐进迁移**: 按里程碑分阶段迁移，每阶段独立验证
5. **风险前置**: 优先处理 SW 休眠、权限缺失等高风险项
