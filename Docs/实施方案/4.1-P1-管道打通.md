### SB-2 补充：UI 加固与临时配置入口（实施时新增，回写记录）

> 实施过程中根据用户反馈「UI 根本看不到（按钮都在但显示不出来）」与「没有配置按钮」追加，偏离原任务卡范围但封闭了 P1 手动验收第 2/3 步。P3/P5 阶段以正式组件替换。

- **ErrorBoundary**（`src/content/error-boundary.tsx`）：捕获 React 渲染异常，显示降级提示框，避免整个 UI 空白。P3 阶段 SC-3 接线时保留或替换为正式错误展示组件。
- **MutationObserver**（`src/content/index.tsx` 内）：监听 documentElement/body 的 childList 变化，host 丢失时自动重新挂载，应对 bilibili.com SPA 路由切换。
- **ToggleButton + SettingsButton**：右下角两个圆形按钮（粉色"聊"切换面板、白色齿轮打开设置）。P3 阶段 SA-7/SC-2 用正式 ToggleButton + Panel 替换。
- **临时 SettingsPanel**（`src/content/settings-panel.tsx`）：极简版 provider 配置 UI，从 `BUILT_IN_PROVIDERS` 读取 9 项，输入 apiKey/model + 单选活动 provider，保存调 `saveBiliAgentSettings`。**P5 SA-12 用正式 4 组件（SettingsPanel/ProviderList/ProviderForm/TestConnectionButton）替换**，本临时文件应删除。
- **host 样式**：从 `width:0;height:0` 改为 `position:fixed;top:0;left:0;width:100vw;height:100vh;pointer-events:none`（子元素 `pointer-events:auto` 恢复交互），规避 Shadow DOM 内 `position:fixed` 子元素在 0×0 host 下包含块失效问题。
- **connectChatPort try-catch**（`src/content/port-connection.ts`）：对 `chrome.runtime.connect` 包 try-catch，失败降级返回空操作 PortConnection，避免 React 树崩溃。
