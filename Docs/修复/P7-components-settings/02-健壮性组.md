## 发现的问题清单

### 问题 1 · ⑦并发/资源泄漏 · 🔴致命

- **位置**：`src/components/model-settings/TestConnectionButton.tsx:106-170`
- **问题**：testing 进行中切换 provider prop 时，旧 listener 和旧 timer 永不清理。新 handleClick 因 status 已是 testing 直接 return，旧 SW 回复仍触发旧 listener 的 resolve。
- **修复建议**：

```tsx
useEffect(() => {
  setStatus("idle")
  setErrorMessage("")
  setIsTimeout(false)
  cleanup()
}, [provider])
```

### 问题 2 · ⑦并发/资源泄漏 · 🔴致命

- **位置**：`src/components/model-settings/TestConnectionButton.tsx:88,95,113,170`
- **问题**：cleanup 是 useCallback 依赖 port，port 变化时 effect cleanup 用新 port 闭包调 removeListener，但 listener 在旧 port 上，removeListener 无效。
- **修复建议**：用 `activePortRef` 固化本次测试的 port，cleanup 移除 port 依赖。

### 问题 3 · ⑦并发/资源泄漏 · 🟠严重

- **位置**：`src/components/model-settings/SettingsPanel.tsx:234-236`
- **问题**：setTimeout 定时器在卸载时未清理，组件卸载后 setState。
- **修复建议**：用 savedTimerRef 保存，卸载时 clearTimeout。

### 问题 4 · ⑦并发/资源泄漏 · 🟠严重

- **位置**：`src/components/model-settings/TestConnectionButton.tsx:106-170`
- **问题**：port.onDisconnect 未监听，SW 崩溃/断连后前端无限等待至 12s 超时。
- **修复建议**：监听 onDisconnect 立即失败。

### 问题 5 · ⑩错误处理缺失 · 🔴致命

- **位置**：`src/components/model-settings/SettingsPanel.tsx:185-221`
- **问题**：多自定义 provider 时部分授权成功部分失败，已授权的权限不回滚，导致权限膨胀。
- **修复建议**：收集已授权 pattern，失败时 `chrome.permissions.remove` 回滚。

### 问题 6 · ⑩错误处理缺失 · 🟠严重

- **位置**：`src/components/model-settings/TestConnectionButton.tsx:153`
- **问题**：port.postMessage 未 try/catch，Port 已断连时抛错无人处理。
- **修复建议**：同步包 try/catch。

### 问题 7 · ⑧性能问题 · 🟡警告

- **位置**：`src/components/model-settings/SettingsPanel.tsx:246-346`
- **问题**：100+ 行内联 CSSProperties 对象在每次 render 重建，未 useMemo 缓存。
- **修复建议**：不变样式提到模块顶层，依赖 state 的用 useMemo。
