## 发现的问题清单

### 问题 1 · ⑨安全漏洞 · 🟡警告

- **位置**：`src/components/model-settings/TestConnectionButton.tsx:153`
- **问题**：`port.postMessage({ type: "test_connection", provider })` 将完整 ProviderConfig（含 apiKey 明文）经 Port 传给 SW。Port 通信走 chrome.runtime 内部 IPC，不跨进程边界、不经过网络，因此不存在传输层泄露。但若 SW 端将 provider 写入日志或 console.error，apiKey 可能落盘日志。
- **修复建议**：前端代码本身安全。建议 SW 端 `handleTestConnection` 捕获异常时对 `provider.apiKey` 做脱敏（如 `apiKey.slice(0,4)+'***'`）。

### 问题 2 · ⑨安全漏洞 · 🟡警告

- **位置**：`src/components/model-settings/ProviderForm.tsx:214,220`
- **问题**：apiKey 输入框 `type="password"` 正确，但 `placeholder` 文本 `"请输入 API Key"` 在已填值时仍渲染。本身不泄露密钥，但更严谨做法是已填值时清空 placeholder。
- **修复建议**（可选加固）：`placeholder={provider.apiKey ? "" : "请输入 API Key"}`
