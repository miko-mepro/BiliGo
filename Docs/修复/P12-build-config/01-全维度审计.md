## 发现的问题清单

### 问题 1 · ②类型 · 🔴致命

- **位置**：`tsconfig.app.json:2-24` + `tsconfig.node.json:2-23`
- **问题**：**缺少 `"strict": true`**，导致 strictNullChecks/noImplicitAny/noImplicitThis/strictFunctionTypes 等全部为 false，类型安全形同虚设。
- **修复建议**：在 compilerOptions 顶部添加 `"strict": true`。

### 问题 2 · ②类型 · 🟠严重

- **位置**：`tsconfig.app.json:8-14`
- **问题**：缺少 `"isolatedModules": true`，esbuild/vite 单文件转译可能出错。
- **修复建议**：添加 `"isolatedModules": true`。

### 问题 3 · ⑨安全 · 🟠严重

- **位置**：`manifest.json:1-36`
- **问题**：缺少 `action` 字段。MV3 扩展无 action 时点击工具栏图标无响应。
- **修复建议**：添加 `"action": { "default_icon": {...} }`。

### 问题 4 · ⑨安全 · 🟠严重

- **位置**：`manifest.json:1-36`
- **问题**：缺少 `web_accessible_resources`，content script 使用 Shadow DOM + adoptedStyleSheets 时若需加载外部资源会被阻塞。
- **修复建议**：根据实际资源需求添加。

### 问题 5 · ⑪配置 · 🟠严重

- **位置**：`package.json:24-44`
- **问题**：版本兼容性存疑：`vite ^8.1.1` + `vitest ^2.1.9`（设计用于 vite 5/6）+ `@crxjs/vite-plugin ^2.7.1`（设计用于 vite 5/6）。
- **修复建议**：运行 `npm ls vite` 验证依赖树。

### 问题 6 · ⑨安全 · 🟡警告

- **位置**：`manifest.json:1-36`
- **问题**：缺少显式 `content_security_policy`。
- **修复建议**：添加 `"content_security_policy": { "extension_pages": "script-src 'self'; object-src 'self'" }`。

### 问题 7 · ⑨安全 · 🟡警告

- **位置**：`manifest.json:29-32`
- **问题**：`optional_host_permissions: ["https://*/*", "http://*/*"]` 范围极宽。
- **修复建议**：文档化此权限用途，考虑按需请求子集。

### 问题 8 · ⑫测试覆盖 · 🟡警告

- **位置**：`vitest.config.ts:9-13`
- **问题**：缺少 `coverage` 配置。
- **修复建议**：添加 `coverage: { provider: 'v8', reporter: ['text', 'html'] }`。

### 问题 9 · ⑫测试覆盖 · 🟡警告

- **位置**：`playwright.config.ts:11-41`
- **问题**：缺少 `retries` 配置，CI 上 E2E 易抖动。
- **修复建议**：添加 `retries: process.env.CI ? 2 : 0`。

### 问题 10 · ⑪配置 · 🟡警告

- **位置**：`package.json:1-49`
- **问题**：缺少 `engines` 字段。
- **修复建议**：添加 `"engines": { "node": ">=20.0.0" }`。

### 问题 11 · ⑨安全 · 🟡警告

- **位置**：`eslint.config.js:18-20`
- **问题**：`languageOptions.globals` 仅设 `globals.browser`，service worker 代码使用 `self`/`ServiceWorkerGlobalScope` 会导致 lint 误报。
- **修复建议**：添加 `globals.serviceworker`。

### 问题 12 · ③命名 · 🟡警告

- **位置**：`package.json:2` vs `manifest.json:3`
- **问题**：名称不一致：`bili-go` vs `BiliGo`。
- **修复建议**：在 README 注明对应关系。

### 问题 13 · ⑪配置 · 🔵建议

- **位置**：`package.json:1-49`
- **问题**：缺少 `"sideEffects": false`。
- **修复建议**：添加 `"sideEffects": false` 或 `"sideEffects": ["*.css"]`。

### 问题 14 · ⑪配置 · 🔵建议

- **位置**：`tsconfig.node.json:1-24`
- **问题**：未显式声明 `resolveJsonModule`。
- **修复建议**：添加 `"resolveJsonModule": true`。
