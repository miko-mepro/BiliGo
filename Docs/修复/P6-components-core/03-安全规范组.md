## 发现的问题清单

### 问题 1 · ⑨安全漏洞 · 🟠严重

- **位置**：`src/components/VideoCard.tsx:34-61`
- **问题**：`parseTitle` 用手写正则清洗 B 站返回的 `title` 字段（含 `<em class="keyword">` 高亮标签）。正则无法覆盖所有危险标签（遗漏 `<svg>`/`<math>`/`<img onerror>` 等）。当前因 React JSX 文本节点自动转义而不可利用，但逻辑脆弱：若未来改为 `dangerouslySetInnerHTML` 立即中招。
- **修复建议**：只保留 em 关键字提取，其余一律纯文本，不再尝试删除危险标签：

```tsx
function parseTitle(title: string | undefined): React.ReactNode {
  if (typeof title !== 'string') return null
  const parts = title.split(/(<em[^>]*>.*?<\/em>)/gi)
  return parts.map((part, index) => {
    const emMatch = part.match(/<em[^>]*class=["']keyword["'][^>]*>(.*?)<\/em>/i)
    if (emMatch) {
      const innerText = emMatch[1].replace(/<[^>]+>/g, '')
      return <strong key={index}>{innerText}</strong>
    }
    const cleanPart = part.replace(/<[^>]+>/g, '')
    return <React.Fragment key={index}>{cleanPart}</React.Fragment>
  })
}
```
