## 发现的问题清单

### 问题 1 · ⑦并发/资源泄漏 · 🔴致命

- **位置**：`src/lib/bilibili-client/{hot.ts:30, search.ts:109, suggest.ts:30, tags.ts:37, wbi.ts:109+136}`
- **问题**：所有 fetch 调用无超时，Promise 可能无限期 pending。若 Bilibili 服务端响应缓慢或 TCP 连接挂起，请求将无限等待，导致 service worker 资源无法释放。
- **修复建议**：

```ts
const response = await fetch(url.toString(), {
  headers: { Accept: 'application/json' },
  signal: AbortSignal.timeout(15_000), // 15 秒超时
})
```

### 问题 2 · ⑦并发/资源泄漏 · 🟠严重

- **位置**：`src/lib/bilibili-client/wbi.ts:90-92` + `wbi.ts:112-116`
- **问题**：`refreshWbiKeys` 并发清空 `pendingKeyFetch` 导致重复 nav 请求。当多个并发 `wbiFetch` 同时收到 401/-352 时，每个都会调用 `refreshWbiKeys()`，后者执行 `pendingKeyFetch = undefined`，互相清空对方的单飞 Promise。
- **修复建议**：用版本号（epoch）防止清空更新版本的 pending：

```ts
let refreshEpoch = 0

export async function wbiFetch(input: string | URL, init?: RequestInit): Promise<Response> {
  const response = await fetchSigned(input, init, false)
  if (!(await shouldRefreshAndRetry(response))) return response
  const epoch = ++refreshEpoch
  keyCache = undefined
  return fetchSigned(input, init, true)
}
```

### 问题 3 · ⑦并发/资源泄漏 · 🟡警告

- **位置**：`src/lib/bilibili-client/wbi.ts:123-126`
- **问题**：`shouldRefreshAndRetry` 用 `response.clone()` 复制整个 body，风控场景下可能返回大体积 HTML 页面。
- **修复建议**：改为先读 text 再 JSON.parse，避免双倍内存。

### 问题 4 · ⑧性能问题 · 🔵建议

- **位置**：`src/lib/bilibili-client/{hot.ts:78-88, search.ts:142-152, tags.ts:87-97}`
- **问题**：`toStringValue`/`toNumber`/`stringifyError` 三文件重复定义，违反 DRY。
- **修复建议**：抽取到 `./internal-helpers.ts`。

### 问题 5 · ⑩错误处理缺失 · 🟠严重

- **位置**：`src/lib/bilibili-client/suggest.ts:39`
- **问题**：JSON 解析无 `.catch`，会抛底层 SyntaxError。其他文件均有 `.catch` 处理。
- **修复建议**：

```ts
const body = (await response.json().catch((error: unknown) => {
  throw new Error(`Failed to parse suggest response: ${
    error instanceof Error ? error.message : String(error)
  }`)
})) as BilibiliSuggestResponse
```

### 问题 6 · ⑩错误处理缺失 · 🟠严重

- **位置**：`src/lib/bilibili-client/suggest.ts:36,42,56`
- **问题**：错误类型用原始 `Error` 而非 `BilibiliNetworkError`/`BilibiliApiError`，与 hot.ts/search.ts/tags.ts 体系不一致。
- **修复建议**：改用 `BilibiliNetworkError`/`BilibiliApiError`。

### 问题 7 · ⑩错误处理缺失 · 🟠严重

- **位置**：`src/lib/bilibili-client/search.ts:119-122` + `tags.ts:82`
- **问题**：`sessdata` 未校验，Cookie 头注入风险。若 sessdata 含分号 `;` 或换行 `\n`，可注入额外 Cookie 字段。
- **修复建议**：

```ts
const SESSDATA_PATTERN = /^[A-Za-z0-9_%-]+$/
if (sessdata && !SESSDATA_PATTERN.test(sessdata)) {
  throw new BilibiliApiError('Invalid SESSDATA format')
}
```
