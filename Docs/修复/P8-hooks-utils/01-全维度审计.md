## 发现的问题清单

### 问题 1 · ⑤空指针 · 🔴致命

- **位置**：`src/hooks/useResizable.ts:47-48`
- **问题**：`DEFAULT_MAX_WIDTH = window.innerWidth` / `DEFAULT_MAX_HEIGHT = window.innerHeight` 在模块顶层执行，SSR 或非浏览器环境将抛 `ReferenceError`，或导致默认 maxWidth=0，缩放完全失效。
- **修复建议**：

```ts
const DEFAULT_MAX_WIDTH = typeof window !== 'undefined' ? window.innerWidth : Number.MAX_SAFE_INTEGER
const DEFAULT_MAX_HEIGHT = typeof window !== 'undefined' ? window.innerHeight : Number.MAX_SAFE_INTEGER
```

### 问题 2 · ⑩错误处理 · 🟠严重

- **位置**：`src/utils/sort-filter.ts:14`
- **问题**：`parseDurationToSeconds` 对负数段（如 `'-5:30'`）无校验，返回负秒数，污染排序与过滤。
- **修复建议**：

```ts
if (parts.some((p) => p < 0)) return 0
```

- **修复建议**：在注释中显式说明语义，或 `if (change.newValue === undefined) return`。
