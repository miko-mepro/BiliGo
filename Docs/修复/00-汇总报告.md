## 三、最高风险发现（Top 10）

1. **tsconfig 缺少 strict 模式** → 整个项目类型安全失效
2. **API Key 明文存储 + sanitize 白名单遗漏** → 敏感信息泄露
3. **chrome.permissions.request 脱离用户手势** → 多 provider 保存失败
4. **MutationObserver 永不 disconnect** → 内存泄漏
5. **ErrorDisplay 重试按钮无效** → 用户体验缺陷
6. **useResizable 模块顶层 window 访问** → SSR 崩溃
7. **Panel-settings.test.tsx 伪测试** → 测试无效
8. **sanitize.ts 零测试覆盖** → 安全函数无验证
9. **slang-understand triedKeywords 覆盖 bug** → 数据丢失
10. **所有 bilibili-client fetch 无超时** → SW 永久阻塞
