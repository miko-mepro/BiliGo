## 发现的问题清单

### 问题 1 · ⑨安全漏洞 · 🟡警告

- **位置**：`src/content/error-boundary.tsx:24, 46`
- **问题**：`componentDidCatch` 将完整 `ErrorInfo`（含 `componentStack`、可能含 `error.message`）原样打印到 console，且 fallback UI 直接把 `error.message` 渲染进 Shadow DOM DOM 节点。content script 在第三方页面（bilibili.com）运行，若异常 message 含上游响应敏感字段（如 API Key、Authorization 头、URL 参数），会写入目标页面控制台与 DOM，构成敏感信息泄露。
- **修复建议**：输出前进行脱敏过滤：

```tsx
import { Component, type ErrorInfo, type ReactNode } from 'react'

// 脱敏：屏蔽常见敏感串（API Key / Token / Authorization 头）
const SENSITIVE_PATTERNS: Array<[RegExp, string]> = [
  [/sk-[A-Za-z0-9_-]{16,}/g, 'sk-***'],
  [/Bearer\s+[A-Za-z0-9._-]+/gi, 'Bearer ***'],
  [/Authorization:\s*[^\s]+/gi, 'Authorization: ***'],
  [/[?&](api[_-]?key|token|auth|access_token)=[^&\s]+/gi, '$1=***'],
]

function redact(text: string): string {
  let out = text
  for (const [pattern, replacement] of SENSITIVE_PATTERNS) {
    out = out.replace(pattern, replacement)
  }
  return out
}

export class ErrorBoundary extends Component<ErrorBoundaryProps, ErrorBoundaryState> {
  static getDerivedStateFromError(error: Error): ErrorBoundaryState {
    return { hasError: true, message: redact(error.message ?? '未知错误') }
  }

  componentDidCatch(_error: Error, info: ErrorInfo): void {
    console.error('[BiliAgent] ErrorBoundary caught:', redact(info.componentStack ?? ''))
  }
  // ...
}
```

### 问题 2 · ⑨安全漏洞 · 🔵建议

- **位置**：`src/content/chat-context.tsx:744-781`
- **问题**：`HISTORY_LOAD_EVENT` 监听器通过 `window.addEventListener` 接收 CustomEvent，未校验 `event.target` 或 `event.isTrusted`。任何运行在主页面、可访问 window 的脚本都能 dispatch `new CustomEvent('biliagent:history-load', {detail:{conversationId:evilId}})` 触发 `loadConversation(evilId)`，将任意本地历史记录注入当前会话 state。
- **修复建议**：验证 conversationId 格式：

```tsx
const onLoadHistory = (event: Event): void => {
  const customEvent = event as CustomEvent<{ conversationId: string }>
  const conversationId = customEvent.detail?.conversationId
  // 仅接受形如 conv_<时间戳>_<6位base36> 的合法 ID
  if (!conversationId || !/^conv_\d+_[a-z0-9]{6}$/.test(conversationId)) {
    return
  }
  void (async () => {
    try {
      const data = await loadConversation(conversationId)
      if (!data || data.id !== conversationId) return
      dispatch({ /* REHYDRATE 不变 */ })
      stateRef.current = { ...stateRef.current, assistantPlaceholderCreated: false }
    } catch {
      // 加载失败不阻塞
    }
  })()
}
```
