## 发现的问题清单

### 问题 1 · ⑦并发/泄漏 · 🟡警告

- **位置**：`test/bilibili-client/hot.test.ts:9-11`
- **问题**：缺少 `afterEach` 恢复 `global.fetch` mock。同目录 suggest.test.ts 和 tags.test.ts 都有 `afterEach(() => vi.restoreAllMocks())`，但 hot.test.ts 只 `vi.clearAllMocks()`。`clearAllMocks` 仅清除调用记录，不清除 `mockResolvedValueOnce` 残留实现。
- **修复建议**：添加 `afterEach(() => { vi.restoreAllMocks() })`。

### 问题 2 · ⑫测试覆盖 · 🟡警告

- **位置**：`test/bilibili-client/tags.test.ts:57-69`
- **问题**：缺少 HTTP 网络失败路径（`ok: false`）的测试。`fetchVideoTags` 导入了 `BilibiliNetworkError` 但测试中从未断言该错误类型。
- **修复建议**：添加 `global.fetch = vi.fn().mockResolvedValueOnce({ ok: false, status: 500 })`，断言 `rejects.toThrow(BilibiliNetworkError)`。

### 问题 3 · ⑫测试覆盖 · 🔵建议

- **位置**：`test/bilibili-client/hot.test.ts:50`
- **问题**：调用 `searchHot(20)` 传入 limit 参数，但未断言 URL 中包含 `limit=20`。
- **修复建议**：补充 `expect.stringContaining('limit=20')` 断言。

### 问题 4 · ⑫测试覆盖 · 🔵建议

- **位置**：`test/bilibili-client/suggest.test.ts`
- **问题**：缺少 API 返回空结果的边界测试。
- **修复建议**：添加返回 `{ code: 0, result: { tag: [] } }` 的测试。

### 问题 5 · ⑪配置 · 🔵建议

- **位置**：`test/setup.ts:44`
- **问题**：`as any` 强制转换 chrome mock 对象绕过类型检查。
- **修复建议**：可选改进，定义 `PartialChrome` 接口。

### 问题 6 · ⑫测试覆盖 · 🔵建议

- **位置**：`test/background/stream.test.ts:770-771`
- **问题**：`expect(callOpts.abortSignal).toBeDefined()` 仅验证存在，未验证 10s 超时。
- **修复建议**：可选改进，mock `AbortSignal.timeout` 并断言传入 `10_000`。
