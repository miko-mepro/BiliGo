## 发现的问题清单

### 问题 1 · ⑥逻辑错误 · 🟡警告

- **位置**：`src/config/settings-migration.ts:102`
- **问题**：`return { ...DEFAULT_SETTINGS }` 为浅拷贝，返回对象的 `providers` 数组与模块级常量 `DEFAULT_SETTINGS.providers` 共享同一引用。当前调用链不会触发 bug，但若有调用方对返回值 `providers` 做 push/splice，会污染模块级默认常量。
- **修复建议**：

```ts
return {
  ...DEFAULT_SETTINGS,
  providers: DEFAULT_SETTINGS.providers.map(p => ({ ...p }))
}
```

### 问题 2 · ⑥逻辑错误 · 🔵建议

- **位置**：`src/config/provider-factory.ts:7`
- **问题**：`createModel` 的 switch 无 default 分支。若未来 `ApiFormat` 新增枚举值，运行时无防御。
- **修复建议**：

```ts
default: {
  const _exhaustive: never = config.format
  throw new Error(`不支持的 provider format: ${String(_exhaustive)}`)
}
```
