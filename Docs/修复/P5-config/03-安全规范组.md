## 发现的问题清单

### 问题 1 · ④导入/引用错误 · 🟠严重

- **位置**：`src/config/provider-factory.ts:13,18,23`
- **问题**：`createModel` 的 switch 缺少 default/return。当 `config.format` 为非三值之一时，函数会隐式返回 `undefined`，而函数签名声明为 `LanguageModel`。运行时调用方拿到 `undefined` 会崩溃。
- **修复建议**：

```ts
default: {
  const _exhaustive: never = config.format
  throw new Error(`不支持的 provider format: ${String(_exhaustive)}`)
}
```

### 问题 2 · ⑨安全漏洞 · 🔴致命

- **位置**：`src/config/provider-factory.ts:11,16,21` + `src/config/settings.ts:38`
- **问题**：API Key 明文存储于 `chrome.storage.local`，无任何加密。任何获得 `storage` 权限的同扩展脚本都可读取。且 `sanitize.ts` 的 `SENSITIVE_KEYS` 列表遗漏 `apikey`/`api-key`/`apiKey`，会把 API Key 直接打印到 console/日志。
- **修复建议**：
  1. 扩充 `sanitize.ts` 的敏感键白名单（立竿见影）
  2. 在 `validateProviderConfig` 中增加 API Key 字符集校验（防止控制字符注入 header）
  3. 中长期：将 API Key 用 `chrome.storage.session` + 主密码加密

### 问题 3 · ⑨安全漏洞 · 🟠严重

- **位置**：`src/config/origin-pattern.ts:154`
- **问题**：`isBuiltInProviderOrigin` 每次调用都 `collectBuiltInHostnames()`，若 `BUILT_IN_PROVIDERS` 在运行时被篡改（如恶意依赖 monkey-patch），原本"应一次性快照"的内置列表会动态变化，绕过 origin 白名单。
- **修复建议**：模块顶层缓存一次性快照。

### 问题 4 · ⑨安全漏洞 · 🟡警告

- **位置**：`src/config/session-memory.ts:76`
- **问题**：拒绝写入时调用方无降级处理路径，可能导致用户数据静默丢失。
- **修复建议**：调用方应至少 `console.warn` 记录静默丢弃事件。

### 问题 5 · ⑪配置/环境问题 · 🟡警告

- **位置**：`manifest.json:26`
- **问题**：`host_permissions` 缺少 ollama IPv6 `[::1]`。当用户系统优先解析 IPv6 时，连接会失败。
- **修复建议**：

```json
"host_permissions": [
  // ... 现有条目 ...
  "http://[::1]/*"
],
```

### 问题 6 · ⑪配置/环境问题 · 🟡警告

- **位置**：`src/config/settings-migration.ts:108-114`
- **问题**：规则 2 直用 `record.providers as ProviderConfig[]`，对超大数组无上限保护。恶意构造的超大 providers 会撑爆 storage 配额。
- **修复建议**：

```ts
const MAX_PROVIDERS = 50
const rawProviders = record.providers.slice(0, MAX_PROVIDERS)
```

### 问题 7 · ④导入/引用错误 · 🔵建议

- **位置**：`src/config/session-memory.ts:9`
- **问题**：引用路径 `'../lib/shared-types/index.js'` 与 settings.ts 的 `'../lib/shared-types/provider.js'` 风格不统一。
- **修复建议**：统一引用入口。

## 审计总结

最高风险：**🔴 API Key 明文存储与 sanitize 白名单遗漏**（问题 2）--建议先修该项与"createModel 无 default"（问题 1），其余 🟡/🔵 项可在后续阶段统一处理。
