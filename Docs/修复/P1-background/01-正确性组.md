## 发现的问题清单

### 问题 1 · ⑥逻辑错误 · 🟠严重

- **位置**：`src/background/stream.ts:332`
- **问题**：`result.stream` 强制断言为 `AsyncIterable<TextStreamPart<ToolSet>>`，但同处上方第 322 行已调用 `streamText()`，未对 `result.stream` 可能为 undefined/非预期形状做防御。若 AI SDK 版本升级导致 `stream` 字段语义变化，直接断言会绕过类型保护而无任何运行时校验。当前虽能工作但属隐性契约依赖。
- **修复建议**：

```ts
// stream.ts:332 附近，替换原断言
const stream: AsyncIterable<TextStreamPart<ToolSet>> = result.stream as AsyncIterable<TextStreamPart<ToolSet>>
// 新增运行时校验，防止 SDK 升级后形状不符
if (!stream || typeof stream[Symbol.asyncIterator] !== 'function') {
  throw new Error('streamText returned invalid stream')
}
for await (const part of stream) {
  // ...原有逻辑不变
}
```

### 问题 2 · ⑤空指针/越界 · 🟡警告

- **位置**：`src/background/stream.ts:478-479`
- **问题**：`result.text ?? ''` 已做 nullish 保护 ✅，但 `.trim()` 后 `slice(0, TITLE_MAX_CHARS)` 对中文字符串按 JS UTF-16 码元切片，对包含 emoji 等 surrogate pair 字符可能在中间被截断产生乱码标题。属于 CHARACTER 边界风险。
- **修复建议**：改用 `Array.from` 按码点切片：

```ts
// stream.ts:478-479 附近
const rawTitle = (result.text ?? '').trim()
// 按码点切片，避免 surrogate pair 被截断
const title = Array.from(rawTitle).slice(0, TITLE_MAX_CHARS).join('')
```

### 问题 3 · ⑥逻辑错误 · 🔵建议

- **位置**：`src/background/port-protocol.ts:96-101`
- **问题**：`inferErrorCode` 用 `message.includes('401')` 检测状态码，存在误判风险：如错误文本含 "port 40192" 或 "14012" 也会匹配 '401' 返回鉴权错误码。属逻辑边界不严谨。
- **修复建议**：改用正则边界匹配：

```ts
// port-protocol.ts inferErrorCode 内
if (/\b401\b/.test(message)) return 'AUTH_ERROR'
if (/\b403\b/.test(message)) return 'FORBIDDEN'
if (/\b429\b/.test(message)) return 'RATE_LIMIT'
if (/\b5\d\d\b/.test(message)) return 'SERVER_ERROR'
```

### 问题 4 · ②类型错误 · 🔵建议

- **位置**：`src/background/port-protocol.ts:68` 与 `src/background/stream.ts:68`
- **问题**：`return converted as unknown as ModelMessage[]` 是双重断言。`toModelMessages` 仅简单 spread 原 `role`/`content`/`toolCalls`/`toolCallId` 字段，未做 `ModelMessage` 枚举 union 的真正校验。若 `ChatMessage.role` 未来增加非 'user'/'assistant'/'tool' 的值，会让运行时收到非法 union 成员而无 TS 报错。
- **修复建议**：增加类型守卫：

```ts
// port-protocol.ts
function isModelRole(r: string): r is ModelMessage['role'] {
  return r === 'user' || r === 'assistant' || r === 'tool'
}

export function toModelMessages(messages: ChatMessage[]): ModelMessage[] {
  return messages
    .filter((m): m is ChatMessage & { role: ModelMessage['role'] } => isModelRole(m.role))
    .map((m) => ({ role: m.role, content: m.content, toolCalls: m.toolCalls, toolCallId: m.toolCallId }))
}
```
