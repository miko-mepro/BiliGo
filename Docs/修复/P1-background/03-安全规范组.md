## 发现的问题清单

### 问题 1 · ⑪配置/环境问题 · 🟡警告

- **位置**：`manifest.json:26-27`
- **问题**：`host_permissions` 中硬编码了 `http://localhost/*` 和 `http://127.0.0.1/*`（明文 HTTP），用于 Ollama 本地 provider。两条等价权限存在冗余，且明文 HTTP host 在扩展权限列表中可能被安全扫描工具标记。
- **修复建议**：属于已知设计取舍（Ollama 本地模型）。若要收窄可改为 `"http://127.0.0.1:11434/*"`（仅允许 Ollama 默认端口），但会限制用户自定义 Ollama 端口。当前实现可接受，标记为 informational。

### 问题 2 · ⑪配置/环境问题 · 🟡警告

- **位置**：`src/background/stream.ts:332`
- **问题**：`for await (const part of result.stream as AsyncIterable<TextStreamPart<ToolSet>>)` 使用了 `as` 强制断言。如果 AI SDK 在某版本变更了 `stream` 属性的类型（例如返回 ReadableStream 而非 AsyncIterable），TypeScript 编译期不会报错，但运行时会因 `Symbol.asyncIterator` 缺失而抛出 `TypeError`。这是环境/版本兼容性隐患。
- **修复建议**：使用 SDK 推荐的迭代器 API（如 `fullStream`）：

```ts
// stream.ts:332 附近，替换原断言
// 移除 as 断言，改用 SDK v4+ 推荐的 fullStream
for await (const part of result.fullStream) {
  // ...原有逻辑不变
}
```

需确认当前 AI SDK 版本是否支持 `fullStream`。
