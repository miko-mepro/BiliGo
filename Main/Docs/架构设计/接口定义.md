# BiliGo 接口定义

## 文档概述

本文档定义 BiliGo 项目中所有跨模块、跨上下文的核心接口契约，包括 Port 消息协议、ChatState、ProviderConfig、Tool Schema、Bilibili API 响应类型以及 Storage Schema。所有 TypeScript 类型定义均作为 CS 和 SW 之间的共享契约，修改需同步两端。

## 1. Port 消息协议

Port 消息协议是 Content Script 与 Service Worker 之间通信的唯一契约，定义在 `src/shared/port-messages.ts`，由 CS 和 SW 共同引用。

### 1.1 完整类型定义

```typescript
// src/shared/port-messages.ts

import type { ProviderConfig, Message } from './provider-config';
import type { ChatState } from './chat-state';

/** Port 名称常量 */
export const PORT_NAME = 'bili-agent-chat' as const;

/**
 * Port 消息联合类型
 * CS -> SW 方向: chat-request / ping / cancel / resend-request / ack
 * SW -> CS 方向: chunk / tool-call-start / tool-call-result / done / error / pong / ack
 */
export type PortMessage =
  // ===== CS -> SW =====
  | { type: 'chat-request'; payload: ChatRequest }
  | { type: 'cancel'; payload: { requestId: string } }
  | { type: 'resend-request'; payload: { fromSeq: number; requestId: string } }
  | { type: 'ack'; payload: { messageId: string } }
  | { type: 'ping' }
  // ===== SW -> CS =====
  | { type: 'chunk'; payload: ChunkPayload }
  | { type: 'tool-call-start'; payload: ToolCallStartPayload }
  | { type: 'tool-call-result'; payload: ToolCallResultPayload }
  | { type: 'done'; payload: DonePayload }
  | { type: 'error'; payload: ErrorPayload }
  | { type: 'pong' };

/** 聊天请求 */
export interface ChatRequest {
  /** 请求唯一 ID，用于幂等去重 */
  requestId: string;
  /** 对话消息列表 */
  messages: Message[];
  /** LLM 提供商配置 */
  provider: ProviderConfig;
  /** 启用的工具名列表，undefined 表示使用默认工具集 */
  tools?: string[];
  /** 取消令牌，与 cancel 消息对应 */
  signal?: string;
}

/** 流式文本块 */
export interface ChunkPayload {
  /** 序列号，从 0 递增，用于乱序重组和丢块检测 */
  seq: number;
  /** 文本增量 */
  text: string;
  /** 所属请求 ID */
  requestId: string;
}

/** 工具调用开始 */
export interface ToolCallStartPayload {
  /** 工具调用唯一 ID（由 LLM 生成） */
  id: string;
  /** 工具名称 */
  name: string;
  /** 工具参数（已解析的 JSON 对象） */
  args: Record<string, unknown>;
  /** 所属请求 ID */
  requestId: string;
}

/** 工具调用结果 */
export interface ToolCallResultPayload {
  /** 工具调用唯一 ID（与 ToolCallStartPayload.id 对应） */
  id: string;
  /** 工具名称 */
  name: string;
  /** 执行结果 */
  result: unknown;
  /** 是否执行失败 */
  isError: boolean;
  /** 所属请求 ID */
  requestId: string;
}

/** 流结束 */
export interface DonePayload {
  /** 结束原因: stop(正常结束) | length(达到最大长度) | tool-calls(以工具调用结束) */
  finishReason: 'stop' | 'length' | 'tool-calls' | 'content-filter';
  /** 所属请求 ID */
  requestId: string;
  /** 总块数（用于完整性校验） */
  totalChunks: number;
}

/** 错误 */
export interface ErrorPayload {
  /** 错误码（见错误码表） */
  code: ErrorCode;
  /** 用户可读的错误消息 */
  message: string;
  /** 所属请求 ID */
  requestId: string;
  /** 原始错误详情（仅开发环境） */
  details?: unknown;
}

/** 错误码枚举 */
export type ErrorCode =
  | 'NETWORK_ERROR'        // 网络连接失败
  | 'API_KEY_INVALID'      // API Key 无效或过期
  | 'API_RATE_LIMIT'       // API 调用限流
  | 'MODEL_NOT_FOUND'      // 模型不存在
  | 'PROVIDER_ERROR'       // Provider 内部错误
  | 'TIMEOUT'              // 请求超时
  | 'PORT_DISCONNECTED'    // Port 连接断开
  | 'CHUNK_GAP'            // 流式响应丢块
  | 'BILIBILI_API_ERROR'   // Bilibili API 调用失败
  | 'TOOL_EXECUTION_ERROR' // 工具执行失败
  | 'UNKNOWN';             // 未知错误
```

### 1.2 消息方向矩阵

| 消息类型 | 方向 | 触发时机 | 是否需确认 |
|---------|------|---------|-----------|
| chat-request | CS→SW | 用户发送消息 | ✅ 是 |
| cancel | CS→SW | 用户取消请求 | 否 |
| resend-request | CS→SW | 检测到丢块 | 否 |
| ack | 双向 | 收到需确认的消息 | 否 |
| ping | CS→SW | 30s 心跳 | 否 |
| chunk | SW→CS | 流式文本增量 | 否 |
| tool-call-start | SW→CS | LLM 发起工具调用 | 否 |
| tool-call-result | SW→CS | 工具执行完成 | 否 |
| done | SW→CS | 流结束 | ✅ 是 |
| error | SW→CS | 发生错误 | 否 |
| pong | SW→CS | 心跳响应 | 否 |

## 2. ChatState 类型

ChatState 是 CS 端维护的聊天状态，定义在 `src/shared/chat-state.ts`。

```typescript
// src/shared/chat-state.ts

import type { ErrorCode } from './port-messages';

/** 聊天状态联合类型 */
export type ChatState =
  | IdleState
  | SendingState
  | StreamingState
  | ToolCallingState
  | DoneState
  | ErrorState;

/** 空闲：等待用户输入 */
export interface IdleState {
  status: 'idle';
}

/** 发送中：请求已发出，等待 SW 响应 */
export interface SendingState {
  status: 'sending';
  requestId: string;
  request: ChatRequest;
  /** 发送时间戳，用于超时检测 */
  sentAt: number;
}

/** 流式接收中：正在接收文本块 */
export interface StreamingState {
  status: 'streaming';
  requestId: string;
  /** 期望的下一个 seq */
  expectedSeq: number;
  /** 已接收的文本 */
  text: string;
  /** 乱序缓冲区 */
  buffer: Map<number, string>;
}

/** 工具调用中 */
export interface ToolCallingState {
  status: 'tool-calling';
  requestId: string;
  /** 当前工具调用 ID */
  toolCallId: string;
  /** 工具名称 */
  toolName: string;
  /** 工具参数 */
  toolArgs: Record<string, unknown>;
}

/** 完成 */
export interface DoneState {
  status: 'done';
  requestId: string;
  /** 最终完整文本 */
  finalText: string;
  /** 结束原因 */
  finishReason: string;
  /** 完成时间戳 */
  completedAt: number;
}

/** 错误 */
export interface ErrorState {
  status: 'error';
  requestId: string;
  code: ErrorCode;
  message: string;
}

/** ChatState 状态转换事件 */
export type ChatStateTransition =
  | { type: 'send'; request: ChatRequest }
  | { type: 'chunk-received'; seq: number; text: string }
  | { type: 'tool-call-start'; id: string; name: string; args: Record<string, unknown> }
  | { type: 'tool-call-result'; id: string; result: unknown }
  | { type: 'done'; finalText: string; finishReason: string }
  | { type: 'error'; code: ErrorCode; message: string }
  | { type: 'reset' };
```

## 4. Tool Schema（Zod 定义）

工具参数使用 Zod 定义，位于 `src/tools/schemas.ts`，AI SDK 会自动转换为 JSON Schema 发给 LLM。

```typescript
// src/tools/schemas.ts
import { z } from 'zod';

/** 搜索 B 站视频参数 Schema */
export const searchBilibiliVideosSchema = z.object({
  keyword: z
    .string()
    .min(1)
    .max(100)
    .describe('搜索关键词，例如 "Python 教程"'),
  page: z
    .number()
    .int()
    .min(1)
    .optional()
    .default(1)
    .describe('页码，从 1 开始，默认 1'),
  pageSize: z
    .number()
    .int()
    .min(1)
    .max(50)
    .optional()
    .default(20)
    .describe('每页数量，1-50，默认 20'),
  order: z
    .enum(['totalrank', 'click', 'pubdate', 'dm', 'stow'])
    .optional()
    .default('totalrank')
    .describe('排序方式：综合/播放/最新/弹幕/收藏'),
});

/** 获取视频详情参数 Schema */
export const getVideoInfoSchema = z.object({
  bvid: z
    .string()
    .regex(/^BV[a-zA-Z0-9]{10}$/, 'BV 号格式不正确，应为 BV 开头 + 10 位字符')
    .describe('视频 BV 号，例如 "BV1xx411c7mC"'),
});

/** 类型推断结果（供 execute 函数使用） */
export type SearchBilibiliVideosParams = z.infer<typeof searchBilibiliVideosSchema>;
export type GetVideoInfoParams = z.infer<typeof getVideoInfoSchema>;
```

### 工具定义（使用 AI SDK）

```typescript
// src/tools/searchBilibiliVideos.ts
import { tool } from 'ai';
import { searchBilibiliVideosSchema } from './schemas';
import { BilibiliClient } from '../bilibili/client';

export const searchBilibiliVideos = tool({
  description: '搜索B站视频。返回视频列表包含标题、UP主、播放量、封面缩略图。用于用户想搜索或查找视频时。',
  parameters: searchBilibiliVideosSchema,
  execute: async ({ keyword, page, pageSize, order }) => {
    const client = new BilibiliClient();
    const result = await client.searchVideos(keyword, page, pageSize, order);
    return {
      total: result.data.numResults,
      videos: result.data.result.map((v) => ({
        bvid: v.bvid,
        title: v.title.replace(/<[^>]+>/g, ''),
        author: v.author,
        play: v.play,
        cover: v.pic,
        duration: v.duration,
      })),
    };
  },
});

// src/tools/getVideoInfo.ts
export const getVideoInfo = tool({
  description: '获取B站视频详细信息，包括标题、简介、时长、UP主、播放量、弹幕数、点赞数、标签。当需要某个视频的完整信息时使用。',
  parameters: getVideoInfoSchema,
  execute: async ({ bvid }) => {
    const client = new BilibiliClient();
    const data = await client.getVideoInfo(bvid);
    return {
      bvid: data.bvid,
      title: data.title,
      desc: data.desc || '无简介',
      duration: data.duration,
      owner: { name: data.owner.name, mid: data.owner.mid },
      stat: {
        view: data.stat.view,
        danmaku: data.stat.danmaku,
        reply: data.stat.reply,
        favorite: data.stat.favorite,
        like: data.stat.like,
        coin: data.stat.coin,
        share: data.stat.share,
      },
      tags: data.tags?.map((t) => t.tag_name) ?? [],
    };
  },
});

// src/tools/index.ts
import { searchBilibiliVideos } from './searchBilibiliVideos';
import { getVideoInfo } from './getVideoInfo';

export const allTools = {
  searchBilibiliVideos,
  getVideoInfo,
};

/** 按名称获取工具子集 */
export function getTools(names?: string[]) {
  if (!names) return allTools;
  const subset: Record<string, typeof allTools[keyof typeof allTools]> = {};
  for (const name of names) {
    if (name in allTools) subset[name] = allTools[name];
  }
  return subset;
}
```

### Storage 读写接口

```typescript
// src/storage/settings.ts
import { StorageKeys, DEFAULT_SETTINGS, SettingsStorage, ProviderStorageEntry } from './keys';

export class SettingsStore {
  async get(): Promise<SettingsStorage> {
    const result = await chrome.storage.sync.get(StorageKeys.SETTINGS);
    return { ...DEFAULT_SETTINGS, ...result[StorageKeys.SETTINGS] };
  }

  async set(settings: Partial<SettingsStorage>): Promise<void> {
    const current = await this.get();
    const merged = { ...current, ...settings };
    await chrome.storage.sync.set({ [StorageKeys.SETTINGS]: merged });
  }

  async getProviderConfig(providerId: ProviderId): Promise<ProviderStorageEntry | undefined> {
    const settings = await this.get();
    return settings.providers[providerId];
  }

  async setProviderConfig(providerId: ProviderId, entry: ProviderStorageEntry): Promise<void> {
    const settings = await this.get();
    settings.providers[providerId] = entry;
    await this.set({ providers: settings.providers });
  }
}
```
