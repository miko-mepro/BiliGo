# BiliGO BugFix 问题档案

## 简介

本档案目录是基于三份原始问题记录文档整理拆分而成的问题知识库。三份原始文档分别针对不同的用户报告现象进行独立调查，记录了 `Main/` 目录下 Chrome 扩展实现中已确认的代码问题、高风险竞态和待验证假设。

原始文档包括：

1. `docs/网络连接错误问题记录.md` —— 调查对话前连接测试、对话后流式请求、Port 通信和工具内网络失败的错误处理链路。
2. `docs/搜索结果展示与重排问题记录.md` —— 调查搜索辅助内容展示时机、自动滚动行为、视频结果生命周期和客户端排序覆盖问题。
3. `docs/渲染崩溃问题记录.md` —— 调查高频点击不同按钮后的渲染崩溃入口、异步竞态和 E2E 测试阻塞。

本档案将上述文档中已确认的代码问题按技术域重新分类归档，形成6个一级分类目录，便于按领域检索和修复。原始文档保留在 `docs/` 根目录，本档案是其分类索引，不替代原始文档中的完整调查上下文和复现证据要求。

## 与原始文档的关系

本档案目录不替代原始问题记录文档，二者关系如下：

- **原始文档**（`docs/` 根目录）保留完整的调查上下文，包括调用路径、已有保护机制、复现所需最小证据和未能从代码确认的事项。原始文档按用户报告的现象组织，适合理解单个现象的完整调查链路。
- **本档案目录**（`docs/问题档案/`）按技术域重新分类，适合按领域检索问题、分析共性问题特征和规划修复批次。每个分类 README 引用了原始文档中的代码位置，但不重复完整调查叙述。
- 修复任一问题时，应同时参阅对应分类 README 和原始文档，确保不遗漏原始文档中记录的复现证据要求和边界条件。
- 本档案中所有标记为"已确认"的问题均有原始文档中的静态代码证据支撑；标记为"待验证"的假设不能仅凭静态代码分析确定，需要运行时证据确认。
